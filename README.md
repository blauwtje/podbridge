# podbridge

A free Windows app that makes AirPods Pro 3 the mic and the output in Discord at once, with stereo output and a wideband mic. It was built for an Asus TUF A15 FA507NV (Realtek RTL8852BE Bluetooth) with Secure Boot on. It uses no kernel driver and no test signing.

While podbridge runs, it owns the laptop's Bluetooth radio, so Windows Bluetooth is off. The radio goes back to Windows when podbridge exits.

## Install

1. Download `podbridge-setup.exe` from the GitHub Release.
2. Double-click it and accept the UAC prompt.
3. SmartScreen shows "Windows protected your PC": click "More info", then "Run anyway".
4. Accept the one driver prompt (VB-CABLE).
5. Restart Windows.
6. Click "podbridge" in the Start Menu and hold the AirPods case button once. The first run pairs the AirPods and saves the pairing in `%APPDATA%\podbridge`.

## Run and Discord devices

Click "podbridge" in the Start Menu, or run `podbridge run`. It prints the devices to pick in Discord:

- Input device: `CABLE Output`
- Output device: `Default`

While it runs, podbridge mutes the Windows default output (the laptop speakers). It captures that output and sends it to the AirPods. `--output-source <device>` captures another device instead and mutes nothing.

Other commands: `podbridge pair` (pair again), `podbridge firmware` (download Realtek firmware into `%APPDATA%\podbridge\firmware`; the installer already bundles it), `podbridge selftest`.

## Doctor

Start Menu "podbridge doctor", or `podbridge doctor`. It checks each stage in order and stops at the first failure: admin rights, Realtek USB ID, firmware files, WinUSB bind, Bumble transport and firmware load, bond, A2DP codec, AAP mic frames per second, VB-CABLE devices, loopback audio while muted. Results are appended to `%APPDATA%\podbridge\doctor.log`.

## Restore

podbridge gives the Realtek driver back on exit. If Bluetooth is still missing in Windows, for example after a crash, run `podbridge restore` (Start Menu "podbridge restore").

`podbridge restore --remove-cert` also deletes the "libwdi autogenerated" certificates from the LocalMachine `Root` and `TrustedPublisher` stores. The uninstaller runs it.

### Manual fallback

If `podbridge restore` fails, open an admin terminal and list the drivers:

```
pnputil /enum-drivers
```

Find the libwdi WinUSB entry (published name `oemNN.inf`) and run:

```
pnputil /delete-driver oemNN.inf /uninstall /force
pnputil /scan-devices
```

Or restart Windows. Then Windows reinstalls the Realtek driver.

## Notices

- Firmware: the installer bundles the unmodified Realtek firmware files from the Linux kernel firmware tree, with `LICENCE.rtlwifi_firmware.txt`, in `<install>\firmware`.
- VB-CABLE: the installer bundles the VB-CABLE driver pack from www.vb-cable.com. It is donationware by VB-Audio; see their site to donate. It is installed only when no "CABLE Input" device exists.
